# Krista Chatbot Extension

## Overview

The Krista Chatbot Extension with Omni-Channel functionality provides a seamless, embeddable chat interface that extends Krista's powerful automation capabilities across various communication channels. This extension acts as an intermediary between the Omni SDK and Krista Platform, delivering a robust conversational experience while accommodating complex input fields.

## Key Features

✅ **Omni-Channel Integration** - Broaden reach across various communication channels

✅ **Seamless User Experience** - Eliminates app-switching issues common in other platforms

✅ **Easy Embedding** - Easily adaptable widget for any web application

✅ **Guest Authentication** - Streamlined authentication through the Authentication Extension

✅ **Customizable UI** - Configurable chatbot appearance, themes, and branding

✅ **Context Data Passing** - Pass contextual data from hosted websites to the chatbot

✅ **Conversation Transcripts** - Retrieve and manage conversation history

✅ **Session Management** - Track and manage user sessions effectively

## Quick Start Guide

1. **Install Authentication Extension** - Set up Guest Authentication extension as a prerequisite
2. **Add Chatbot Extension** - Navigate to Essential Ecosystem → Collaboration Domain
3. **Configure Extension** - Set up welcome conversation, UI config, and fallback conversation
4. **Embed Widget** - Add the chatbot script to your website
5. **Test Integration** - Use the Krista Hosted Extension preview to test functionality
