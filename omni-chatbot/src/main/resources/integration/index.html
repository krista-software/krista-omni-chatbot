Quick Integration

Copy the code below and paste it into your website's HTML in two steps.

Step 1: Add to the <head> tag


<link rel="stylesheet" href="_basePath_ui/launcher.css"/>
<script src="_basePath_ui/launcher.js"></script>

Step 2: Add before closing </body> tag

<script>
  const options = {
    host: "_basePath_"
  }
  const kristaChatbot = new Chatbot(options);
  kristaChatbot.init();
</script>
