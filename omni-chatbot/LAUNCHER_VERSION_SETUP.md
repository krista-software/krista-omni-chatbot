# Launcher Version Setup Guide

## Problem
When building a JAR file, the launcher version needs to be set at **build time** (baked into the JAR), not at runtime.

## Solution
The version is now read from **`launcher.properties`** file which is auto-generated during build from `.env` file.

---

## How It Works

### Priority Order
The Java code reads the launcher version from multiple sources in priority order:

1. **Environment variable** (runtime) - `LAUNCHER_VERSION=v2`
2. **Properties file** (build-time) - `src/main/resources/launcher.properties`
3. **Default** - `v1`

### Code Implementation
```java
private static String getLauncherVersion() {
    // Priority 1: Environment variable (runtime)
    String envVersion = System.getenv("LAUNCHER_VERSION");
    if (envVersion != null && !envVersion.isEmpty()) {
        return envVersion;
    }
    
    // Priority 2: Properties file (build-time)
    try (InputStream input = Constants.class.getClassLoader()
            .getResourceAsStream("launcher.properties")) {
        if (input != null) {
            Properties prop = new Properties();
            prop.load(input);
            String propVersion = prop.getProperty("launcher.version");
            if (propVersion != null && !propVersion.isEmpty()) {
                return propVersion;
            }
        }
    } catch (IOException e) {
        // Ignore and fall back to default
    }
    
    // Priority 3: Default
    return "v1";
}
```

## Setup Steps

### Step 1: Set Version in .env File
Edit `omni-chatbot/src/main/ui/.env`:
```bash
LAUNCHER_VERSION=v2
```

### Step 2: Build Launcher Files
```bash
cd omni-chatbot/src/main/ui
npm run build-launcher
```

This generates:
- `dist/launcher-core-v2.js`
- `dist/launcher-v2.js`
- `dist/launcher.css`

### Step 3: Update launcher.properties
Edit `omni-chatbot/src/main/resources/launcher.properties`:
```properties
launcher.version=v2
```

**Note:** This file should be auto-generated by Gradle during build, but if the Gradle task fails, update it manually to match the `.env` file.

### Step 4: Build JAR
```bash
cd omni-chatbot
./gradlew clean build
```

The JAR will now use `v2` as the launcher version.

### Step 5: Verify
After deploying the JAR, test the API:
```bash
curl http://your-server/chatbot/launcher
# Should return: launcher-core-v2.js
```

## Gradle Auto-Generation (Optional)

The `build.gradle` includes a task to auto-generate `launcher.properties` from `.env`:

```gradle
task generateLauncherProperties {
    doLast {
        def envFile = file("$projectDir/src/main/ui/.env")
        def propsFile = file("$projectDir/src/main/resources/launcher.properties")
        
        propsFile.parentFile.mkdirs()
        
        def launcherVersion = "v1" // default
        
        if (envFile.exists()) {
            envFile.eachLine { line ->
                if (line.startsWith("LAUNCHER_VERSION=")) {
                    launcherVersion = line.substring("LAUNCHER_VERSION=".length()).trim()
                }
            }
        }
        
        propsFile.text = "launcher.version=${launcherVersion}\n"
        println "✔ Generated launcher.properties with version: ${launcherVersion}"
    }
}
```

This task runs automatically before `processResources` during the build.

**If Gradle build fails** (e.g., Java version issues), manually update `launcher.properties` to match `.env`.

## Changing Versions

### For Development (Quick Test)
Use environment variable to override without rebuilding:
```bash
LAUNCHER_VERSION=v3 java -jar omni-chatbot.jar
```

### For Production (Permanent)
1. Update `.env`:
   ```bash
   echo "LAUNCHER_VERSION=v3" > src/main/ui/.env
   ```

2. Rebuild launcher:
   ```bash
   cd src/main/ui
   npm run build-launcher
   ```

3. Update properties file:
   ```bash
   echo "launcher.version=v3" > src/main/resources/launcher.properties
   ```

4. Rebuild JAR:
   ```bash
   ./gradlew clean build
   ```

5. Deploy new JAR

## Troubleshooting

### Problem: API returns "launcher-core-v1.js" but I set v2

**Check 1: Verify .env file**
```bash
cat omni-chatbot/src/main/ui/.env
# Should show: LAUNCHER_VERSION=v2
```

**Check 2: Verify launcher files exist**
```bash
ls -la omni-chatbot/src/main/ui/dist/launcher-core-*.js
# Should show: launcher-core-v2.js
```

**Check 3: Verify properties file**
```bash
cat omni-chatbot/src/main/resources/launcher.properties
# Should show: launcher.version=v2
```

**Check 4: Verify properties file in JAR**
```bash
unzip -p omni-chatbot/build/libs/omni-chatbot.jar launcher.properties
# Should show: launcher.version=v2
```

**Check 5: Verify UI files in JAR**
```bash
unzip -l omni-chatbot/build/libs/omni-chatbot.jar | grep launcher-core
# Should show: ui/launcher-core-v2.js
```

### Problem: Gradle build fails with "Unsupported class file major version 68"

This is a Java version compatibility issue. **Workaround:**

1. Manually update `launcher.properties`:
   ```bash
   echo "launcher.version=v2" > src/main/resources/launcher.properties
   ```

2. Build without running the Gradle task:
   ```bash
   ./gradlew build -x generateLauncherProperties
   ```

Or use a compatible Java version (Java 17 or 21).

### Problem: Files not found after deployment

**Solution:** Ensure UI files are copied to resources during build:
```bash
./gradlew clean buildUI build
```

This runs:
1. `clean` - Cleans old files
2. `buildUI` - Builds UI and launcher files
3. `build` - Builds JAR with all resources

## Best Practices

### ✅ Keep .env and launcher.properties in sync
Always update both files when changing versions:
```bash
# Update .env
echo "LAUNCHER_VERSION=v3" > src/main/ui/.env

# Update properties
echo "launcher.version=v3" > src/main/resources/launcher.properties
```

### ✅ Build launcher before building JAR
```bash
cd src/main/ui && npm run build-launcher && cd ../..
./gradlew clean build
```

### ✅ Version control
- ✅ Commit `launcher.properties` to git (it's the build-time version)
- ❌ Don't commit `.env` to git (add to `.gitignore`)
- ✅ Document the version in release notes

### ✅ Multiple environments
Use different versions for different environments:
- Dev: `launcher.version=dev`
- QA: `launcher.version=qa`
- Prod: `launcher.version=v1`

**Files to keep in sync:**
